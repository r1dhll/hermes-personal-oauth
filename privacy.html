Hermes Personal

Privacy policy

Last updated: 16 September 2026

This policy is for Hermes Personal, a private desktop agent used only by Ridhul Vidhul. Contact: ridhulvidhul76@gmail.com.

Google user data this app accesses

When Ridhul signs in with Google, Hermes Personal may access:

  • Gmail — read, send, label, and modify mail he asks the agent to handle
  • Google Calendar — read, create, update, and delete events he asks the agent to handle
  • Google Drive, Docs, Sheets, and Contacts — only if those permissions were granted at sign-in

How that data is used

Google user data is used only to carry out Ridhul’s own requests in Hermes (for example: “what is on my calendar”, “find this email”, “create this event”). It is not used for advertising. It is not sold. It is not used to train public AI models.

How that data is stored

Google issues access and refresh tokens. Those tokens are stored only on Ridhul’s Mac, in Hermes’ local config folder, so the agent can keep working after the short access token expires. Mail, events, and files are not copied into a separate cloud database for this app. Hermes may show snippets in the chat window while answering a request.

How that data is shared

Hermes Personal does not share Google user data with other people or companies, except:

  • Google, when the agent calls Google’s APIs to do the requested action
  • The AI model provider Hermes is using for that chat, which sees the text of the request and whatever mail/calendar text the agent includes in that turn so it can answer

A separate n8n setup on Ridhul’s Hostinger server may use its own Google login for automations. That is not this app.

Retention and deletion

Tokens stay on the Mac until Ridhul disconnects the app or revokes access in his Google Account (Google Account → Third-party access). Revoking access stops API calls. Chat logs on the Mac follow Hermes’ normal session storage.

Changes

If how Hermes Personal uses Google user data changes, this page will be updated and the date above will change.
